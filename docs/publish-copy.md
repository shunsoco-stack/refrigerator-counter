## ポートフォリオ紹介文

「冷蔵庫の中身は、さっき見たときと同じ。」それでも開けてしまう日常を、ちょっと真面目に記録する Web アプリです。開けた理由、時間帯・週間グラフ、1 日 10・30・50 回の実績解除まで、ひとつの小さな行動に必要以上の丁寧さを詰め込みました。

Next.js App Router / TypeScript / Tailwind CSS で実装。白と半透明を基調にしたモバイルファーストの UI と、押すと扉が少し開くアニメーションを組み合わせています。記録は localStorage に保存し、1 回の取り消し、CSV、共有、ダークモード、PWA・オフライン利用に対応。日付境界や保存失敗も考慮し、「くだらないけれど、つくりは真剣」を目指しました。

## Tsukutta 紹介文

冷蔵庫を開けた回数だけを数える「冷蔵庫カウンター」をつくりました。

ボタンを押すと、冷蔵庫の扉が少し開いて 1 回を記録。「中身はさっきと同じです」と、アプリがわざわざ教えてくれます。飲み物、食べ物、なんとなくなどの理由を選べて、今日・今週・累計やグラフも確認できます。

1 日 10 回で「確認のプロ」、30 回で「冷蔵庫警備員」。50 回まで開けると、さらに実績が解除されます。ログイン不要で、記録は使っているブラウザに保存。CSV、共有、ダークモード、ホーム画面への追加にも対応しています。

在庫は管理しません。献立も考えません。開けたという事実だけは、ちゃんと残します。
